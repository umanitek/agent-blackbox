Protection mode

Every tool call and model request is checked before it runs, in both modes. The mode decides what happens to a threat Blackbox finds.

Audit or Block Reading the saved mode… Audit records and flags threats but lets them run. Block also refuses them before they run. Switching to Audit turns protection down, so it waits for your approval; Block applies at once.
Block from severity In Block mode, verified threats at this severity or higher are refused; lower ones are only flagged. A lower level blocks more and applies at once; a higher one blocks less and waits for your approval. In Audit mode it has no effect.

A call larger than this can not be read, so it has not been checked — and a call that has not been checked is refused, never let through. A larger limit lets bigger calls through, each still checked, at the cost of memory and time; a smaller one refuses more. Neither direction lets an unchecked call through, so this change applies at once.
