# blackbox-netd release binaries — the installer checks each download against these SHA-256 values.
# Release tag: blackbox-helper-v0.1.0 (assets named as below). Regenerate this file with every new build.
#
# HOW IT IS REGENERATED. There is no script: this file is the installer's trust anchor (the
# repository, not the download server), so it changes only together with a release the owner
# publishes. Building alone publishes nothing:
#   1. set `version` in plugins/blackbox/helper/Cargo.toml to the new release's version;
#   2. on a Mac, in plugins/blackbox/helper:
#        cargo build --release --locked --target aarch64-apple-darwin
#        cargo build --release --locked --target x86_64-apple-darwin
#      and copy target/<triple>/release/blackbox-netd to blackbox-netd-darwin-arm64 and
#      blackbox-netd-darwin-x86_64 (the asset names scripts/blackbox-install.sh asks for);
#   3. `shasum -a 256 blackbox-netd-darwin-*` and put each line below, `version` set to the same
#      version; the owner uploads the two files to the release tag blackbox-helper-v<version>;
#   4. commit this file with the release (never before the assets are up: an install would refuse
#      the old download against the new SHA-256, and fall back to "system protection not installed").
# LINUX (SUPPORTED since 2026-11-24; NO Linux asset is published yet and none is listed below, so
# an install on Linux says "no published helper for this machine in this release yet" and a
# locally built one installs with BLACKBOX_HELPER_PATH + BLACKBOX_HELPER_SHA256). The release adds,
# built static on each architecture (Blackbox CI builds both on every helper change, uploading nothing):
#        cargo build --release --locked --target x86_64-unknown-linux-musl
#        cargo build --release --locked --target aarch64-unknown-linux-musl
#      copied to the asset names the installer asks for (helper_asset_name):
#        blackbox-netd-linux-x86_64   blackbox-netd-linux-arm64
#      and, for the agent sandbox launcher, blackbox-sandbox-linux-x86_64 / -arm64;
#      each line `sha256sum`'s, as above.
